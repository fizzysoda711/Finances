**FINANCE APP INFORMATION**

**App Goals**
-
User can:
- Input expenditures by category with amount spent, date, and an optional note. Note: if no date is entered, it will use the date at the time the entry was made.
- Create categories with a name and an optional budget.
- See overall spending or spending by category as well as if the budget has been surpassed.
